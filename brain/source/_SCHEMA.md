# Source artifacts — schema

Raw material: transcripts, forwarded emails, meeting recordings' notes, pasted
customer messages, exported analyst reports. **Never rewritten** once added — if the
transcript was wrong, add a note, don't edit the record.

This is the target of the `[source/<path>](../source/<path>)` provenance tag
(PLATFORM.md §4.1) — used when the raw artifact is self-explanatory enough that a
separate ingestion/synthesis file would be ceremony.

There is no fixed sub-structure here (unlike `ingestion/`); organize by whatever
grouping keeps the raw material findable — by date, by stakeholder, by source
system. A source file is never a decision or hypothesis input directly; it is only
ever a link target.
